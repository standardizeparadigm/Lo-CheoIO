## 1. Tổng quan

v1.1.1 là bản **vá lỗi toàn diện** đồng thời **mở rộng** dự án theo hai trục: (1) **i18n trong game** — toàn bộ chuỗi hiển thị (HUD canvas, popup, banner, màn hình, ticker) nay đều đi qua dictionary đa ngôn ngữ **Tiếng Việt · English · 中文**, chuyển đổi tức thì, không cần tải lại; (2) **tài liệu** — README nâng cấp lên **7 ngôn ngữ** với 2 asset SVG animation mới và mục FAQ đầy đủ. Bên cạnh đó, toàn bộ mã nguồn được rà quét lại một lượt để **tìm và sửa hết mọi lỗi** phát hiện được (xem mục 3). Không có breaking change; dữ liệu người chơi giữ nguyên.

## 2. Tính năng mới

### 2.1 Chuyển đổi ngôn ngữ trong game (VI ⇄ EN ⇄ ZH)
- **Module i18n thuần** `src/i18n/`:
  - `i18n.ts` — không phụ thuộc React: phát hiện ngôn ngữ ban đầu (localStorage `locheo.lang.v1` → `navigator.language` → `vi`), lưu lựa chọn, `t(key, params?, lang?)` với **nội suy `{param}`** và **fallback về vi** khi thiếu key; export `numberLocale()` / `fmtNum()` để số theo đúng locale (vi-VN / en-US / zh-CN).
  - `useI18n.ts` — cầu nối React: `useI18n()` trả `{ lang, t }`, đăng ký re-render qua sự kiện `locheo:languagechange`.
  - `locales/vi.ts` (**nguồn key set** — 166 key), `locales/en.ts`, `locales/zh.ts` (mirror bắt buộc, ép bởi test).
- **`LanguageSwitcher.tsx`** — nút phân đoạn **VI · EN · 中** dùng chung hai nơi:
  - Menu chính: góc trên phải, bản đầy đủ kèm globe icon + nhãn "Ngôn ngữ".
  - Màn Tạm nghỉ: dưới cùng, bản compact.
- **Toàn bộ chuỗi hiển thị đã bản địa hoá**:
  - Canvas HUD: `KỶ LỤC`, `CẤP n`, `n HŨ · n CỦ`, nhãn `HŨ DƯA`, combo `n CHUỖI`, chip `ỚT HIỂM ×2` / `ĐÁ LẠNH` / `TỎI VÀNG ×n` / `LẮC HŨ ✦ SẴN SÀNG`, nhãn chế độ đáy màn hình, `CHÉO!`, `KỶ LỤC`.
  - Banner & popup: `MUỐI NÀO!`, `HŨ ĐẦY! +bonus`, `CẤP n`, `CAY XÈ!`, `NGÂM ĐÁ`, `KHIÊN TỎI!`, mọi popup cộng điểm/khiên/đập/ném hỏng.
  - Màn hình: menu (badge trực tiếp từ bếp, kỷ lục, mô tả, 6 rules, touch/keyboard hints, ticker 14 mục), pause, game over (kèm tên mặc định "KHÔNG TÊN/ANON/无名"), thành tựu (tên + mô tả 10 huy hiệu), bảng vàng (tiêu đề/đơn vị cấp-hũ/TOP n), nút mute/pause (aria-label), hint đáy màn hình, `<html lang>` đồng bộ khi đổi ngôn ngữ.
- **Không reset ván đang chơi**: engine canvas đọc dictionary ở mỗi frame nên HUD đổi ngôn ngữ ngay lập tức; React screens re-render qua sự kiện.
- **Lưu lựa chọn** vào `locheo.lang.v1`; storage bị chặn thì giữ trong bộ nhớ.

## 3. Sửa lỗi (bugfixes)

| # | Lỗi | Mức độ | Cách sửa |
| --- | --- | --- | --- |
| 1 | **Chuỗi hiển thị tiếng Việt hardcode khắp nơi** (HUD, popup, banner, menu, pause, game over, thành tựu, ticker, aria-label) — game không thể dùng ở ngôn ngữ khác | Cao (blocker cho i18n) | Toàn bộ đi qua `t()`; thêm test mirror key set 3 locale + placeholder + interpolation |
| 2 | **`ScoreBoard` luôn format số theo vi-VN** kể cả khi UI ở en/zh | Nhẹ | Dùng `fmtNum(n, lang)` theo ngôn ngữ đang chọn |
| 3 | **Engine canvas không đọc được ngôn ngữ React** (module tách biệt) | Cao (i18n không hoạt động trong HUD) | `i18n.ts` là module thuần giữ `activeLanguage` ở module scope; `t()` đọc trực tiếp — HUD đổi ngay frame kế tiếp, không qua React state |
| 4 | **`t()` chỉ dùng được trong React** nếu thiết kế theo context thuần | Thiết kế | API `t(key, params?, lang?)` — engine truyền lang tuỳ ý, mặc định `activeLanguage`; hook `useI18n` chỉ còn là cầu nối re-render |
| 5 | **`<html lang>` sai/không đổi khi chuyển ngôn ngữ** (luôn "vi") | Nhẹ (a11y/SEO) | App sync `document.documentElement.lang` theo ngôn ngữ đang chọn |
| 6 | **Thiếu fallback khi key chưa dịch** — rủi ro màn hình trắng chữ | Trung bình | `t()` fallback vi → fallback raw key; test bắt buộc 3 locale đồng key set |
| 7 | **Tên mặc định khi lưu kỷ lục** "KHÔNG TÊN" cứng tiếng Việt | Nhẹ | Key `save.anonymous` (KHÔNG TÊN / ANON / 无名) |
| 8 | **Aria-label nút mute/pause/touch-slam** cứng tiếng Việt (screen reader đọc sai ngôn ngữ) | Nhẹ (a11y) | Tất cả aria-label qua `t()` |
| 9 | **`npm run typecheck` "xanh giả"** khi `node_modules` chưa cài — `npx tsc` tải nhầm package `tsc@2.0.4` từ registry | Tooling | Cài deps bằng `npm ci`; tài liệu nhấn mạnh `npm run typecheck` dùng script local |
| 10 | **README mô tả sai số liệu** (tests 36, link thiếu bản dịch mới, không có hướng dẫn i18n) | Docs | Cập nhật toàn bộ README (7 bản): 45 tests, cấu trúc mới, mục i18n + FAQ |

## 4. Cải thiện (improvements)
- **i18n kiến trúc 2 lớp**: module thuần (test được, dùng ở canvas engine lẫn React) + hook React chỉ để re-render — không state trùng lặp, không context provider.
- **Số theo locale**: `fmtNum()` — 1.234.567 (vi) / 1,234,567 (en) / 1,234,567 (zh) thống nhất mọi nơi (HUD, bảng vàng, pause, game over, menu).
- **Placeholder an toàn**: test kiểm tra `{param}` của vi == en == zh cho mọi key có tham số — dịch thiếu placeholder sẽ fail CI.
- **Docs đồng bộ 100%**: README ×7, CHANGELOG, CONTRIBUTING (mục "Thêm ngôn ngữ mới", 45 tests), index.html meta description/keywords (VI + i18n), banner V1.1.1.
- **9 unit tests mới** (`tests/i18n.test.ts`): parity key 3 locale, placeholder, interpolation, `numberLocale`, persist/detect — tổng **45 tests**.
- **2 SVG animation mới** cho tài liệu (demo gameplay + bảng nguyên liệu).

## 5. Kiểm thử & chất lượng
- `npm run typecheck` — sạch (strict + noUnusedLocals).
- `npm run test` — **45/45 pass** (vitest 3.2.7).
- `npm run build` — `dist/index.html` ~655 KB (gzip ~330 KB), single-file OK.
- Không có môi trường browser automation trong sandbox build (binary bị chặn từ v1.1.0) → kiểm tra render thủ công khuyến nghị trên Chrome/Firefox/Safari + Android. Build artifact đã verify tự chứa bằng cách soi output (không URL ngoài; fonts inline).
- **Giới hạn đã biết**: canvas HUD dùng font hệ thống cho glyph CJK (Be Vietnam Pro/Bungee không chứa CJK) — tiếng Trung hiển thị bằng font dự phòng của hệ điều hành, vẫn đầy đủ và đúng vị trí; các glyph latin giữ nguyên Bungee/Be Vietnam Pro.
- `prefers-reduced-motion` được tôn trọng (aurora/shimmer/spin/sheen); sao nền và screen shake theo media query.

## 6. Tương thích & nâng cấp từ v1.1.0
- **Dữ liệu người chơi**: không đổi key nào hiện có; thêm **key mới** `locheo.lang.v1` (ngôn ngữ) — xoá key này chỉ làm game về mặc định vi/theo trình duyệt.
- **API nội bộ**: `src/i18n/*` là module mới; không xoá/không đổi public API của engine/components; `MODES[*].name` và `ACHIEVEMENTS[*].name/description` vẫn còn nhưng UI không còn dùng trực tiếp (dictionary là nguồn hiển thị) — giữ lại để tương thích/test.
- **Hành vi**: gameplay, vật lý, cân bằng, điểm số — **không thay đổi**; chỉ lớp hiển thị.
- Cần **Node ≥ 20.19** để build; người chơi chỉ cần trình duyệt hiện đại — không ảnh hưởng.
