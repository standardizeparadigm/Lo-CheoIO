## 1. Tổng quan

v1.1.3 là bản **mở rộng nội dung chơi** tiếp nối v1.1.2, với trục chính *"càng chơi càng cuốn, càng ở lại lâu"*: bổ sung **2 chế độ hoàn toàn mới** — **MƯA DƯA** (mưa dưa dày ~1.4× nhưng ×0.75 điểm, "lụt dưa" đúng nghĩa) và **GỐM MỎNG** (chỉ MỘT vết nứt là vỡ hũ, ×2.0 điểm — chế độ hardcore thực sự), cùng **2 thành tựu mới** (tổng **14**). Song song, game được quốc tế hóa thật sự: **5 ngôn ngữ giao diện trong game** — thêm **日本語** và **한국어** bên cạnh Tiếng Việt · English · 中文 (193 khóa dịch mỗi locale, đồng bộ `<html lang>`, số theo locale). Bên ngoài game, bộ **launcher double-click** cho macOS/Windows/Linux nay **đa ngôn ngữ** (phím `L`: VI→EN→中, biến môi trường `LOCHEO_LANG`) với **hoạt họa** 3 nháy + spinner braille kèm % thật — và menu tiếng Việt hiển thị **dấu đầy đủ**. Cuối cùng, dự án có **favicon web** hoàn chỉnh (`favicon.ico` multi-size + SVG động + data-URI nhúng), README cả 10 ngôn ngữ được đồng bộ, `npm run check` xanh với **55 unit tests**. Không có breaking change; dữ liệu người chơi giữ nguyên.

## 2. Tính năng mới

### 2.1 Chế độ **MƯA DƯA** (`storm`) — "lụt dưa"
- **Luật**: dưa rơi **chậm hơn** một chút (`speedMult 0.88`) nhưng **dày gấp ~1.4×** (`spawnMult 0.72` — khoảng cách spawn ngắn hơn), đồ hư **nhiều gấp 1.5×** (`hazardMult 1.5`), đổi lại mỗi củ chỉ **×0.75 điểm** (`scoreMult 0.75`).
- **Cảm giác**: ngập lụt dưa — mưa cả bếp, tay lia không kịp, leo cấp cực nhanh nhờ mật độ dày. Là chế độ "chống chán" hoàn hảo cho người đã thuộc lòng Cổ điển.
- **Thành tựu liên quan**: `storm-60` — **CƠN MƯA NẶNG HẠT** (hứng 60 củ trong một ván Mưa Dưa).
- **i18n**: `mode.storm.name/tagline/desc/badge`, `ach.storm-60.name/desc` — đủ trong **vi / en / zh / ja / ko** (parity ép bởi test).

### 2.2 Chế độ **GỐM MỎNG** (`hardcore`) — hardcore thật sự
- **Luật**: gốm lò non tay — chỉ chịu được **đúng MỘT vết nứt** (`maxCracks: 1` trong `ModeConfig`). Chạm đồ hư một lần là **vỡ hũ ngay**. Đền bù: **×2.0 điểm** mỗi củ (`scoreMult 2`), hazard ×1.3, spawn ×0.95, speed ×1.1.
- **Kỹ thuật**: engine đọc `MODES[mode].maxCracks ?? 3` thay vì hằng số toàn cục — vừa cho ngưỡng vỡ hũ, vừa cho nhãn popup `popup.cracked/broken`.
- **Thành tựu liên quan**: `hardcore-jar` — **GỐM THÉP** (đầy một hũ trong một ván Gốm Mỏng).
- **Dành cho**: người chơi lâu năm, săn điểm & thành tựu "khó nhằn" nhất game.

### 2.5 i18n **5 ngôn ngữ** trong game — thêm 日本語 · 한국어
- **2 locale mới**: `src/i18n/locales/ja.ts` và `ko.ts` — **193 khóa** mỗi bản, dịch tay đầy đủ (không máy móc từng từ), văn phong game tự nhiên; parity test ép **5 locale** đồng bộ key set (kể cả placeholder).
- **Tích hợp**: kiểu `Language` = `"vi" | "en" | "zh" | "ja" | "ko"`; `LANGUAGES` thêm `ja`/`ko`; auto-detect theo `navigator.language` (`ja`, `ko`, `ja-JP`, `ko-KR`); `numberLocale` thêm `ja-JP` / `ko-KR`; khóa lưu `locheo.lang.v1` giữ nguyên (giá trị mới được chấp nhận).
- **`LanguageSwitcher`** (dùng chung menu chính + màn pause): segmented control 5 nút — **VI · EN · 中 · 日 · 한**.
- **Fallback**: thiếu key → `t()` tự về tiếng Việt (như cũ) — không crash, không ô trống.
- **Mọi chuỗi mới/hiện có** đều đã có mặt trong cả 5 locale — test `i18n.test.ts` (11 tests) ép đồng bộ.

### 2.6 Launcher đa ngôn ngữ + **hoạt họa** (`scripts/`) — macOS · Windows · Linux
- **Đổi ngôn ngữ ngay trong launcher**: phím **`L`** chuyển vòng **VI → EN → 中**; biến môi trường **`LOCHEO_LANG=vi|en|zh`** đặt ngôn ngữ mặc định; tiếng Việt hiển thị **dấu đầy đủ** (menu, banner, trợ giúp, prompt).
- **Hoạt họa/hiệu ứng**: **banner 3 nháy** (3 khung màu gold/emerald/rose, chỉ chạy khi stdout là TTY — pipe/redirect không còn in rác escape), **spinner braille** (`⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏`) kèm **phần trăm thật** trong lúc build, **sparkle line** (`✦ ·˚`) trang trí trước menu.
- **`play-linux.sh`** (Linux): sửa `spin_run` (ký hiệu `spin_run <log> <label> -- <lệnh…>`), banner TTY-guarded, sparkle line gọi đúng chỗ, mặc định `LANG=vi` khi env trống — đã **chạy thật** trong sandbox (menu + option 4 → 55/55 tests pass).
- **`play-mac.command`** (macOS): subtitle "TRÌNH CHẠY MACOS" (3 ngôn ngữ), hướng dẫn cài Node qua **Homebrew** (`brew install node`), mở game bằng **`open`**, header comment rõ ràng; `bash -n` sạch.
- **`play-windows.bat`** (Windows): viết lại hoàn toàn — `chcp 65001` + UTF-8 để menu tiếng Việt có dấu; ANSI màu thô; menu đa ngôn ngữ qua nhánh `:vi/:en/:zh`; gợi ý cài Node qua **winget** (`winget install OpenJS.NodeJS.LTS`); mở game bằng `start "" dist\index.html`; `cls` giữa các khung banner; CRLF. **Chưa chạy thật trên Windows** (không có môi trường) — đã rà soát cú pháp tĩnh; khuyến nghị người dùng xác nhận.
- **`scripts/README.md`**: viết lại — bảng 3 hệ điều hành, yêu cầu Node ≥ 20.19, phím `L` / `LOCHEO_LANG`, danh sách hoạt họa, bảng menu & nền tảng.

## 4. Cải thiện (improvements)
- **Game content**: 5 → **7 chế độ**; 12 → **14 thành tựu**; phá vỡ hũ theo **từng chế độ** (`maxCracks`) — thêm chiều sâu chiến lược cho người chơi giỏi.
- **Quốc tế hóa**: 3 → **5 ngôn ngữ** trong game (vi/en/zh → + **ja/ko**); parity test 5 locale; launcher cũng đa ngôn ngữ.
- **Onboarding**: launcher `L` đổi tiếng ngay tại menu; hướng dẫn Homebrew/winget theo OS; animation giúp người mới đọc menu dễ hơn.
- **Web polish**: favicon đầy đủ mọi kích cỡ + SVG động; `<html lang>` xử lý ja/ko; number locale ja-JP/ko-KR.
- **Docs**: README 10 ngôn ngữ đồng bộ 1.1.3; assets `modes.svg` 7 chip; `DESCRIPTION.md` đa ngôn ngữ cập nhật; release notes này.

## 5. Kiểm thử & chất lượng
- `npm run typecheck` — TypeScript strict, sạch (0 lỗi, `noUnusedLocals`).
- `npm run test` — **55/55 pass** (4 file: modes 20 · achievements 13 · storage 11 · i18n 11).
- `npm run build` — `dist/index.html` một file (~690 KB, gzip ~346 KB), **không còn asset rời bị hash** (favicon inline).
- **Launcher Linux đã chạy thật**: menu vi/en/zh render sạch (piped), option 4 → 55/55 tests pass. Launcher macOS: `bash -n` sạch + render menu zh OK. Launcher Windows: **chưa chạy thật** (không có cmd.exe) — chỉ rà soát tĩnh; CRLF + `chcp 65001` được đảm bảo.
- Không có browser automation trong sandbox → khuyến nghị kiểm tra thực tế trên Chrome/Firefox/Safari + mobile; mọi SVG animation (banner/demo/items/modes/favicon) đều SMIL, chạy trên GitHub `<img>`.
- `prefers-reduced-motion` vẫn được tôn trọng trong game; CTA launcher cũng không tự chạy animation khi pipe.

## 6. Tương thích & nâng cấp từ v1.1.2
